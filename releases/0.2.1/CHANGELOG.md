# 0.2.1

- The SAM OpenCode Plugin authorizes native run-bound Steering for ordinary managed Agent roots and advertises the additive `run-bound-steering/v1` capability under Wire v3.
- Managed provider requests can use Steering input verified against the original root and native admission metadata.
- The release uses the qualified OpenCode 2.3.0 executable from 0.2.0. Stateless Completion, background job authority and ordinary root admission retain their previous contracts.
